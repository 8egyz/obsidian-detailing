# Obsidian Detailing

Учебный проект (Midterm) по курсу Web Technologies 1 (Front End).
Сайт детейлинг-студии премиум-класса в Астане.

- Репозиторий: https://github.com/ИМЯ/obsidian-detailing
- Сайт: https://ИМЯ.github.io/obsidian-detailing/

## Страницы

| Страница | Что внутри |
|---|---|
| index.html | Главная: hero, цифры, преимущества, шаги, отзывы |
| services.html | Пакеты, таблица цен, FAQ (Bootstrap accordion) |
| works.html | Слайдер до/после, галерея на Grid |
| booking.html | Форма записи с расчётом цены |
| contacts.html | Контакты, график работы, карта |

## Технологии

HTML5 (семантика), CSS (Flexbox, Grid, переменные, media queries), Bootstrap 5.3, немного JavaScript.
